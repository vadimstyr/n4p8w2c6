# ePlanTranScript Updates

Dieses Repository enthaelt nur Installer und Update-Pakete.

Der Quellcode bleibt im privaten Repository und ist hier nicht enthalten.

## Erstinstallation

Unter Releases die Datei `ePlanTranScript-win-Setup.exe` herunterladen und ausfuehren.
Danach prueft die installierte App beim Start selbst auf neue Versionen.
